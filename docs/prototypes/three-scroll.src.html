How I build

Problem to store, part by part.

  1. Discover. Use the thing.
  2. Define. Decide what it is not.
  3. Design. In SwiftUI, on a real device.
  4. Build. Offline-first, secure where money is.
  5. Refine. Tests behind every release.
  6. Ship. Submit, get approved, repeat.
